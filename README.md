# Nuance

**Dire les choses avec justesse.**

Assistant d'écriture pour les messages délicats : il rend votre propre message, retouché au minimum (changements surlignés), avec un curseur pour aller plus loin — et il aide à prendre du recul sur un message reçu avant d'y répondre.
